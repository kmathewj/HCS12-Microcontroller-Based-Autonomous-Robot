# HCS12-Microcontroller-Based-Autonomous-Robot

## Overview
Programmed and constructed a mobile robot with line tracking and obstacle avoidance capabilities using assembly language on the HCS12 microprocessor development system, successfully interfacing motors and sensors to achieve reliable autonomous navigation.
Integrated and tested robotic control algorithms that enhanced artificial intelligence decision-making for path correction, applying strong analytical and problem-solving skills to ensure consistent performance across varied environments.
